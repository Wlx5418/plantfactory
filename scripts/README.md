# 植物工厂管理系统 - 脚本说明

## 脚本文件

### start.bat
- **功能**: 启动植物工厂管理系统
- **端口**: 后端9091，前端5173
- **特性**:
  - 启动前自动检查端口占用
  - 自动启动后端和前端服务
  - 显示访问地址和登录信息

### kill_ports.bat
- **功能**: 清理端口占用和相关进程
- **端口**: 清理9091和5173端口
- **特性**:
  - 智能检测端口占用
  - 清理Java和Node.js进程
  - 等待确保端口完全释放

## 使用方法

### 启动系统
```batch
双击运行 scripts\start.bat
```

### 重启服务
```batch
先运行 scripts\kill_ports.bat
再运行 scripts\start.bat
```

### 停止服务
```batch
运行 scripts\kill_ports.bat
```

## 默认配置

- **后端端口**: 9091
- **前端端口**: 5173
- **登录账号**: admin / admin123456

## 注意事项

- 确保MySQL服务已启动
- 确保已安装Java 17+和Node.js 16+
- 启动前会自动检查端口占用情况
